# RWNS - A Robot Walkin'n'Shootin game

This is a game that was inspired by Timeline Up, which I played without spending any real money or
watching any ads.

This game does not ask for money and does not show ads. I've built it for myself. I'll be happy if
anybody else likes it, too.

RWNS runs on [github pages](https://jacekkopecky.github.io/rwns). Intended to run on a
portrait-oriented mobile touch screen.

Agents, see `./AGENTS.md` and `./TESTING.md` for various instructions for consistency.
